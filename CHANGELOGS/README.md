# SolarLanDroid Changelogs

This directory contains the version changelogs. Why? `release.yml` fetches from this folder, and gets the content from this directory to put as a changelog.

---

For **developers**, please use this format;
```markdown
## Added
- {lists of added}

## Updated
- {lists of updated}

## Fixed
- {lists of fixed}

## Removed
- {lists of removed}

## Misc
- {lists of misc}
```
